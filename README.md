# repo-testers

## Laboratório de Testes de Software

Este repositório foi criado com foco em aprendizado autodidata na área de QA (Quality Assurance) e testes de software. O objetivo é centralizar estudos, práticas e experimentos utilizando aplicações públicas e ambientes permitidos para testes.

## Áreas abordadas

- Testes automatizados
- Testes funcionais
- Testes de API
- Testes de integração
- Testes de segurança
- Testes de performance
- Testes de carga (Load Test)
- Testes de estresse (Stress Test)
- Testes de pico (Spike Test)
- Automação com Python
- Ferramentas utilizadas pelo mercado de QA
- ci/cd

## Objetivo do projeto

A proposta deste repositório é desenvolver conhecimento técnico de forma prática, documentando estudos, ferramentas, scripts, relatórios e experimentos relacionados a QA e automação de testes.

Os testes realizados devem utilizar apenas ambientes autorizados, plataformas públicas para estudo ou aplicações disponibilizadas para fins educacionais e laboratoriais.

## Finalidade

Este projeto não possui objetivo ofensivo, competitivo ou malicioso. O foco é exclusivamente educacional e técnico, visando evolução profissional e aprofundamento em engenharia de qualidade de software.

> "Conhecimento é uma das poucas coisas que ninguém pode retirar de alguém."
